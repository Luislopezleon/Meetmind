# 1. Overview del Proyecto

## 🎯 Descripción del Problema

Las reuniones corporativas generan información valiosa que se pierde:
- **Decisiones importantes** no se documentan adecuadamente
- **Action items** se olvidan o no se asignan claramente
- **Riesgos y preocupaciones** mencionados no se rastrean
- **Preguntas abiertas** no tienen seguimiento
- Los participantes deben tomar notas manualmente, distrayéndolos de la discusión
- Los resúmenes son inconsistentes o inexistentes

## 💡 Solución Propuesta: MeetMind

Un **agente de IA autónomo** que:

1. **Se une automáticamente** a reuniones como participante silencioso
2. **Transcribe en tiempo real** con identificación de speakers
3. **Detecta automáticamente** decisiones, action items, riesgos y preguntas
4. **Asigna tareas** a las personas mencionadas en la reunión
5. **Sincroniza con herramientas** (Jira, Notion) al finalizar
6. **Genera resumen ejecutivo** estructurado automáticamente
7. **Muestra todo en tiempo real** en un dashboard web

- **Event-driven Architecture**: Processing de audio/texto en tiempo real
- **Product Engineering**: Construir algo que impresione visualmente
